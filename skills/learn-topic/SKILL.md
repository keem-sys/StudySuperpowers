# Learn a topic

## Purpose

Build the student's understanding of a course topic through progressive explanation and short checks for comprehension, using the student's course materials as the primary source.

## When to use

Use this workflow when a topic, definition, process, or prerequisite is unclear. It is not a request to produce a long summary or to teach an entire course at once.

## Required and optional inputs

**Required:** A topic or question to learn.

**Optional:** Lecture notes or slides, learning outcomes, textbook excerpts the student may share, prior knowledge, preferred level of detail, and a particular application or example.

If the student asks for a course-specific explanation but no course material is available, say that the answer cannot be grounded in their course and ask them to share the relevant material or accept a clearly labelled general explanation. For a simple general question, answer directly with that limitation instead of adding unnecessary setup questions.

## Step-by-step procedure

1. **Choose the right depth.** For a simple, narrow question, answer it directly in a concise explanation and ask one comprehension question. For a complex topic, use the structured sequence below. Do not begin with a long introduction or apply every step when it adds no value.
2. **Scope only as needed.** Identify the relevant course source and official learning outcome if available. Ask a clarifying question only when the missing detail would materially change the explanation. For a complex topic, check prerequisites only when they affect the next teaching step; never invent prerequisites. Label your own objectives as suggested, not official.
3. **Teach in focused steps.** Begin with the core idea and explain unfamiliar terms before relying on them. Build toward mechanisms, relationships, and applications as appropriate. Use a worked example or analogy when it improves understanding. Keep each turn proportional to the request.
4. **Ground the explanation.** Distinguish course-supported claims from analogy, inference, or additional general knowledge. Refer to a document, section, slide, or page only when you can verify it. If sources conflict, state the conflict and ask which version applies before relying on it.
5. **Check understanding.** During an interactive learning exchange, ask no more than one comprehension question per response and wait for the student's answer. For a direct-answer request, answer directly and offer an optional follow-up question without requiring the student to answer it.
6. **Diagnose and adapt the response.** Assess correctness, completeness, and reasoning where relevant. First acknowledge correct ideas. Accept different wording when the meaning is correct. Distinguish an incomplete answer, a misconception, a terminology mix-up, and a claim unsupported by the sources.
	- If the answer is partly correct, name what is right and the specific gap; offer a hint or retry when useful.
	- If it reveals a misconception, explain the precise mismatch with a short example, then ask a different question that checks the corrected idea.
	- If the wording is different but the concept is right, confirm the meaning and optionally supply the course term.
	- If recall is correct but application is uncertain, increase difficulty with one application, comparison, or reasoning question. Do not repeat the same question unnecessarily.
7. **Bound and close the session.** Adapt the number of checks to the topic's complexity and the student's demonstrated understanding. After roughly three to five comprehension checks, use the student's progress to decide whether to pause and provide a brief update, asking whether they want to continue, practise further, or move on. Pause earlier when the topic is simple or the student is struggling. Do not prolong a session merely to reach a question count. If the student asks to stop, stop questioning and summarise what was covered, what they demonstrated, remaining gaps or uncertainty, and a useful next step.

## Expected output

A response sized to the request: either a direct explanation with one check, or a structured, progressive lesson with relevant sources, objectives, prerequisites, examples, and misconception checks as useful. During teaching, ask one question and wait. Adapt to the student's answer and finish with a concise progress summary when the student stops or the session reaches a natural pause.

## Guardrails and failure handling

- Do not substitute a long summary for interactive understanding checks.
- Do not force a formal lesson structure onto a simple question or ask clarifying questions that will not change the answer.
- Do not invent course facts, page references, learning outcomes, or prerequisites. Say when a source cannot be read or located.
- If the student's answer makes a specific claim the supplied material does not establish, distinguish “not supported by these sources” from “incorrect.” Do not confirm or reject the claim without evidence; label any outside explanation and ask for a course source when needed.
- If sources conflict, describe the conflict and ask which source or course version to use. Do not silently resolve it.
- Ask exactly one comprehension question per teaching turn and wait for the student's answer before evaluating it. Never reveal the answer in the same turn.
- If the student asks for a direct answer, answer directly and optionally offer one follow-up practice question. Do not imply that understanding was tested when it was not.
- Stop when the student asks to stop. Do not claim mastery from one correct answer or continue questioning indefinitely.
- Keep explanations within the course scope unless the student requests broader context, which must be labelled as additional.

## Evaluation criteria

A successful session matches the depth to the request; uses only verifiable course sources and outcomes; labels suggested objectives and additional knowledge; explains unfamiliar terms; asks one question and waits; recognizes correct content before diagnosing gaps; accepts semantically correct alternative wording; changes the next step based on the response without repeating questions; sets a reasonable stopping point; and summarizes evidence-based progress without overclaiming mastery.

## Usage example

> In one or two sentences, explain carrying capacity using my course notes, then ask me one question to check that I understand.
