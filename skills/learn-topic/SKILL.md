# Learn a topic

## Purpose

Build the student's understanding of a course topic through progressive explanation and short checks for comprehension, using the student's course materials as the primary source.

## When to use

Use this workflow when a topic, definition, process, or prerequisite is unclear. It is not a request to produce a long summary or to teach an entire course at once.

## Required and optional inputs

**Required:** A topic or question to learn.

**Optional:** Lecture notes or slides, learning outcomes, textbook excerpts the student may share, prior knowledge, preferred level of detail, and a particular application or example.

If materials are not available, say that explanations cannot be grounded in the student's course sources and ask whether they want a general explanation. Label general knowledge accordingly.

## Step-by-step procedure

1. **Scope the topic.** Restate the topic briefly. Identify the most relevant supplied sources and learning outcomes. Ask a focused question if the request is too broad or ambiguous.
2. **Establish a starting point.** Identify prerequisites from the material where possible. Ask what the student already knows when that will change the explanation. Do not invent prerequisite requirements.
3. **Set objectives.** Translate the relevant learning outcomes into a small set of things the student should be able to explain or do. If no outcomes are supplied, label these as suggested objectives.
4. **Explain progressively.** Start with the core idea and essential vocabulary, then build toward relationships, mechanisms, or applications. Use a worked example when useful. Keep each portion focused rather than delivering a long summary.
5. **Separate evidence from explanation.** State which points are supported by the uploaded material. Clearly label an analogy, inference, or additional explanation, and do not present it as a course source claim.
6. **Surface likely misconceptions.** Name one or more plausible confusions relevant to the material and explain the distinction without implying the student holds the misconception.
7. **Check comprehension.** Ask exactly one question, then stop and wait. Do not include its answer or another question in the same turn.
8. **Respond to the student's answer.** Evaluate what is correct and what needs work, using a brief reason. If there is a misconception, address it with a targeted explanation and a different check. If the answer shows understanding, increase the application or reasoning demand gradually.
9. **Adapt and conclude.** Continue one question at a time until the student asks to stop or the objectives have been reasonably checked. Summarise what was covered, what the student demonstrated, remaining uncertainty, and a suggested next step.

## Expected output

A focused, source-aware learning exchange: scoped topic, objectives and prerequisites when available, progressive explanations with examples, explicitly labelled source support versus additional explanation, misconception checks, and one-at-a-time comprehension questions. End with a concise progress summary.

## Guardrails and failure handling

- Do not substitute a long summary for interactive understanding checks.
- Do not invent course facts, page references, learning outcomes, or prerequisites. Say when a source cannot be read or located.
- If the student's answer makes a specific claim the supplied material does not establish, distinguish “not supported by these sources” from “incorrect.” Do not confirm or reject the claim without evidence; label any outside explanation and ask for a course source when needed.
- If sources conflict, describe the conflict and ask which source or course version to use. Do not silently resolve it.
- Keep each question singular and wait for the student's answer before evaluating it.
- If the student asks for an answer directly, answer at an appropriate level, then offer a chance to explain or apply it; do not falsely imply that retrieval practice occurred.
- Keep explanations within the course scope unless the student requests broader context, which must be labelled as additional.

## Evaluation criteria

A successful session identifies the requested topic and relevant sources; uses available objectives and prerequisites accurately; builds from fundamentals; gives suitable examples; differentiates source-supported claims from additions; flags plausible misconceptions; asks one question and waits; and changes subsequent support based on the student's demonstrated understanding.

## Usage example

> Use `learn-topic` for carrying capacity using my course notes. Begin with any prerequisite concepts you find, explain the idea with one example, then ask me one comprehension question and wait for my answer.
