# Verify your study setup

After adding your Project instructions and course materials, paste this prompt into a new chat in that Project:

```text
Before we study, check this setup without guessing:

1. List the course files or sources you can actually access by name. Do not say you read a file unless you can access its contents.
2. Briefly list the topics or learning outcomes you can identify from those sources.
3. Tell me if anything is missing, unreadable, unclear, or contradictory.
4. Confirm how I can ask you to use learn-topic, active-recall, or exam-marker with the StudySuperpowers instructions in this Project.

Do not start a study session yet. If you cannot access any course material or the StudySuperpowers instructions, tell me exactly what to add or paste.
```

If the reply names the wrong files or misses a source, re-add the file under the Project's course materials area and ask the check again. For other issues, see [Troubleshooting](troubleshooting.md).
