# Advanced study setup

The beginner setup is enough to use all three workflows. Use these options when you want more continuity or a more tailored study routine.

## Reuse a progress summary

At the end of a session, ask for a short summary and check it for accuracy. Save it as a Project source if the platform supports that, or keep a course note and paste it into a later session. A summary is a reminder, not proof of mastery.

```text
Course and topic:
Materials used:
Objectives covered:
What I could explain or apply:
Unclear points to revisit:
Suggested next step:
```

## Customise the study routine

You can add preferences to the end of the Project instructions, such as your course level, preferred explanation length, or a request to include more application questions. Keep the source rules and selected workflow requirements intact. For example, do not remove the instruction to wait for an answer in active-recall.

For platform-specific instructions, see the [Claude guide](../platforms/claude/setup.md) or [ChatGPT guide](../platforms/chatgpt/setup.md). For privacy, course permissions, and academic integrity, see [Privacy and limitations](privacy-and-limitations.md).
